# Dawn theme instructions

- Follow Online Store 2.0 theme conventions.
- Preserve existing section setting IDs and merchant configuration.
- Prefer small, reusable snippets over duplicated Liquid markup.
- Keep changes compatible with the theme editor.

# Process documentation

- Read `docs/JURNAL.md` at the start of each work session for previous decisions and pending work.
- Update `docs/JURNAL.md` as work progresses and before the final response for any session that performs project work.
- Write journal entries in Romanian, append them chronologically, and preserve earlier entries. Correct earlier information through an explicit follow-up entry.
- Record the date, user request, actions and decisions, affected files, verification results, and any blockers or next steps. Include failed attempts when they explain the outcome.
- Distinguish completed work from planned work. Link relevant existing Git commits when useful; do not invent prior activity or claim unperformed checks.
- Never record credentials, tokens, secrets, or unnecessary personal data. Summarize actions rather than copying raw conversations or command output.
- The journal documents work performed in these sessions; it is not automatic monitoring of actions outside them. Follow the user's current instructions if they change the documentation scope.
